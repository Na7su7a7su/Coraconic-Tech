# 核龙科技 (Coraconic Tech)

NeoForge 1.21.1 科技模组，当前处于早期开发阶段。

## 当前状态

- 开发中，注册名、配方和数值可能随时调整
- 暂不保证存档兼容
- 仓库不公开，README 仅作为开发记录
- 目标环境：Minecraft 1.21.1 / NeoForge 21.1.259+ / Java 21

## 模组定位

围绕锡、铅、核龙金属、腾龙金属展开的科技模组，后续逐步扩展材料加工与科技内容。

## 已实现内容

### 金属

- 锡
- 铅
- 核龙金属
- 腾龙金属

### 物品

- 锡锭、铅锭、核龙金属锭、腾龙金属锭
- 锡粒、铅粒、核龙金属粒、腾龙金属粒
- 粗锡、粗铅
- 常金属核心、核龙金属核心、腾龙金属核心
- 核龙元素、腾龙元素
- hcv2（食物）

### 方块

- 锡块、铅块、核龙金属块、腾龙金属块
- 锡矿石、铅矿石
- 深板岩锡矿石、深板岩铅矿石

> 矿石方块已注册，但尚未实现自然生成。

### 配方与标签

- 金属块 ↔ 金属锭（9:1）
- 金属锭 ↔ 金属粒（1:9）
- 核心、元素与金属锭相关配方
- 通用物品标签：`c:ingots`、`c:nuggets`、`c:raw_materials`、`c:ores`、`c:storage_blocks`、`c:foods`

### 本地化

- 英语：`en_us`
- 简体中文：`zh_cn`
- 繁体中文：`zh_hk`、`zh_tw`

### 数据生成

- 方块状态、方块模型、物品模型
- 方块标签、物品标签
- 配方与解锁进度
- 方块战利品表
